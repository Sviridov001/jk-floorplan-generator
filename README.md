# Генератор планировок этажа ЖК (секция 14 м)

Интерактивный веб-прототип для генерации вариантов планировок типового этажа жилой секции глубиной 14 м (`6,1 + 1,8 + 6,1 м`) по мотивам проектов секций **С1** и **С5**.

## Возможности
- Базовые шаблоны секций (**С1** `22,8 × 14 м`, **С5** `41,6 × 14 м`) и свободная настройка длины корпуса (19,2–51,2 м).
- Выбор положения ядра ЛЛУ, включение балконов с коэффициентом 0,3 и настройка целевой квартирографии (`1К / 2К / 3К`).
- Генерация 6 вариантов нарезки с расчётом ТЭП, КЭП, площадей МОП и автоматической экспликацией помещений.
- Экспорт выбранного плана в **SVG** и экспликации в **CSV** (для Excel).

2. Откройте **Settings → Pages → Source: Deploy from a branch (`main` / `/(root)`)**.
